## Аудитория
Zov Zapret расчитан на русских пользователей и иногда английских для FPS буста.
## Как использовать
Использовать очень просто. Выбираете файлик ws.bat и запускаете. Если пишет то что zapret уже запущен, то проверьте интернет соединение.
- Использование service.bat:
> Тут описаны доп. функции, другие смотрите ниже
- 11. Credits - Кредиты на проэкты которые причастны к разработке
- 12. FLC - Fast Language Changer позволит вам быстро сменить регион на компьютере. Пока что тестировалось один раз и вряд ли нормально работает. !! ЕСЛИ СБРОСИЛАСЬ КЛАВА ТО СКАЧАЙТЕ В НАСТРОЙКАХ !!
- 13. Source Opener - Просмотр исходного кода.
- 14. Roblox Thumbnail Fixer Tool - Фиксит картинки и ассеты в Roblox.
- 15. Admin Mode - мод админа. (НЕ РАБОТАЕТ)
- 16. Configs Editor - эдитор конфигов. Загружайте свои конфиги и делитесь ими с друзьями.
## Как скачать
Справа будет плашка Releases нажимаете на последнюю (Latest) и скачиваете zov-zapret.zip или zov-zapret.7z нажав на него.
## Безопасность
Данные не собираются и не передаются. Файлы в открытом доступе и каждый может просканировать запрет. 
Сканы на разных сайтах:
- [VirusTotal](https://www.virustotal.com/gui/file/123b01d7bd08c114a4d4c6951432f6033536721d901ce1b5417f8e578f8dc679?nocache=1)
- [Kaspersky](https://opentip.kaspersky.com/123B01D7BD08C114A4D4C6951432F6033536721D901CE1B5417F8E578F8DC679/results?tab=upload)
> [!CAUTION]
WinDivert может вызвать реакцию антивируса. WinDivert - это инструмент для перехвата и фильтрации трафика, необходимый для работы zapret. Замена iptables и NFQUEUE в Linux, которых нет под Windows. Он может использоваться как хорошими, так и плохими программами, но сам по себе не является вирусом. Драйвер WinDivert64.sys подписан для возможности загрузки в 64-битное ядро Windows.
